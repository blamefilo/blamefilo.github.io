title: filo_jack
---

A realistic **FiveM vehicle jack** that allows players to physically lift either side of a vehicle using floor jacks.

## Features

- Lift either the left or right side independently
- Realistic pump-by-pump animation
- Accurate vehicle roll geometry
- Automatic height compensation
- Support for jacking both sides simultaneously
- Export available for detecting lifted vehicles

## Requirements

- [ox_lib](https://github.com/overextended/ox_lib)
- [community_bridge](https://github.com/TheOrderFivem/community_bridge)

Continue with the installation guide to get started.
